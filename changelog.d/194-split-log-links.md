### Added
- **A run's split log, a click away** (#194): the result strip of the fight that completed a trial or an arena, and the Instance tab, list the split logs that hold the run, each with *open folder*, which opens its folder with the file selected, and *copy path*, which puts its full path on the clipboard for a log site's upload dialog. A run over more than one logging session lists each session's file. With Hide names on, only the file's name shows, there and in the review banner, since a full path names your Windows user. With split logs off, as a fresh install has them, the line says where to turn them on.
